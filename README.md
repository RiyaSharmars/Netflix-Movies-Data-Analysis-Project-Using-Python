# 🎬 Netflix Data Analytics Project Using Python

## 📌 Overview

This project focuses on analyzing Netflix data using Python to uncover trends, patterns, and insights about movies and TV shows. The workflow includes data collection, cleaning, exploratory data analysis (EDA), visualization, and dashboard creation.

The objective of this project is to demonstrate practical data analytics skills such as data preprocessing, visualization, and insight generation using Python libraries. The final output helps understand content distribution, genre trends, and viewer preferences.

---

## 📂 Dataset

The dataset contains information about Netflix movies and TV shows, including details such as:

* Title
* Type (Movie/TV Show)
* Genre
* Country
* Release Year
* Duration
* Rating
* Cast and Director

The data was collected from a public dataset and used for analysis and visualization purposes.

---

## 🛠️ Tools & Technologies Used

* Python
* Pandas – Data manipulation and analysis
* Matplotlib – Data visualization
* Seaborn – Statistical data visualization
* Jupyter Notebook – Development environment

---

## 🔄 Project Steps

### 1️⃣ Data Collection & Loading

* Imported the dataset into Python using Pandas.
* Explored the dataset structure and checked column details.

### 2️⃣ Data Cleaning

* Handled missing values.
* Removed duplicates.
* Standardized column formats.
* Converted data types for accurate analysis.

### 3️⃣ Exploratory Data Analysis (EDA)

* Analyzed content distribution by type, country, and genre.
* Examined release trends over the years.
* Identified most common ratings and categories.
* Explored patterns in movie vs TV show production.

### 4️⃣ Data Visualization

* Created bar charts, line charts, and count plots.
* Visualized trends in Netflix content over time.
* Compared categories and ratings using graphical representations.
* Designed clean and easy-to-understand visual outputs.

---

## 📊 Dashboard & Visual Outputs

The project includes visual insights such as:

* Distribution of Movies vs TV Shows
* Content production trends by year
* Top genres on Netflix
* Country-wise content analysis
* Ratings classification analysis

These visuals help in better understanding Netflix’s content strategy and user preferences.

## 📈 Results & Insights

* Movies dominate Netflix content compared to TV shows.
* Significant growth in content production observed after 2015.
* Certain genres consistently appear more frequently.
* Some countries contribute more content than others.
* Viewer ratings show trends in audience preferences.
